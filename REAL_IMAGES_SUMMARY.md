## 🔄 Easy to Update

Want different images?
1. Visit [Unsplash.com](https://unsplash.com)
2. Search for your destination
3. Copy the photo URL
4. Add `?w=800&q=80` parameters
5. Update CSS in `store/templates/store/homepage.html`
