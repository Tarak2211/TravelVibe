## 🎯 Design Principles

1. **Consistency**: Same border-radius, spacing, colors throughout
2. **Hierarchy**: Clear visual importance levels
3. **Feedback**: Hover states on all interactive elements
4. **Simplicity**: Clean, uncluttered layouts
5. **Delight**: Smooth animations and transitions

## 🎨 Design Elements

### Cards
- White background
- 20px border-radius
- Soft shadow: `0 10px 40px rgba(0,0,0,0.08)`
- Hover shadow: `0 20px 60px rgba(102, 126, 234, 0.2)`

### Buttons
- Gradient: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
- Border-radius: 12px
- Shadow: `0 4px 15px rgba(102, 126, 234, 0.4)`
- Hover shadow: `0 8px 25px rgba(102, 126, 234, 0.6)`

### Inputs
- Border: `2px solid #e2e8f0`
- Border-radius: 12px
- Background: `#f8fafc`
- Focus border: `#667eea`
- Focus shadow: `0 0 0 3px rgba(102, 126, 234, 0.1)`

### Typography
- Font: Poppins
- Heading: 700 weight
- Body: 400 weight
- Links: 500 weight
